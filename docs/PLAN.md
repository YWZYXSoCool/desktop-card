# Desktop Card — v1 策划

> 一个开机自启、带位置记忆、常驻最上层的桌面小卡片。**卡片本身是平台**，
> 音频播放只是其中一个功能（widget）。支持多 widget 切换、搜索、声明式设置。

- **平台**：仅 Windows
- **技术栈**：Tauri 2 + SvelteKit (Svelte 5, SPA 静态模式) + Rust
- **架构**：卡片核心（平台）只认 `WidgetDefinition` 契约；具体功能各自封装成 widget
- **文档状态**：实施中 · 2026-08-11（README 为最新现状，本文为规划基准）

## 1. 功能需求 (Functional)

### 1.1 核心流程
1. 应用启动 → 恢复上次窗口位置（无记录则屏幕居中）。
2. 用户把一个音频文件从资源管理器拖到卡片上并松开。
3. 卡片立即开始播放该文件，显示曲名与进度。
4. 播放期间可进行：播放/暂停、进度拖拽定位、音量调节/静音。
5. 关闭应用 → 记住当前窗口位置，下次启动恢复。
6. 开机 → 应用自动启动并常驻最上层。

### 1.2 功能清单（v1 范围）
| # | 功能 | 说明 | 优先级 |
|---|------|------|--------|
| F1 | 拖入即播 | 拖拽单个音频文件到卡片，松开即播 | P0 |
| F2 | 播放 / 暂停 | 点击按钮或点击卡片主体切换 | P0 |
| F3 | 进度显示 + 拖拽定位 | 进度条可点击/拖动跳转 | P0 |
| F4 | 音量控制 | 音量滑块 + 静音开关，记住上次音量 | P1 |
| F5 | 曲名显示 | 显示文件名（截断+省略号），hover 显示全名 | P0 |
| F6 | 时长显示 | 当前时间 / 总时长 `m:ss / m:ss` | P1 |
| F7 | 位置记忆 | 移动窗口防抖保存，启动恢复 | P0 |
| F8 | 开机自启 | 注册自启动，可在卡片上开关 | P0 |
| F9 | 常驻最上层 | always-on-top | P0 |
| F10 | 拖拽移动窗口 | 无边框下自定义拖拽区移动卡片 | P0 |
| F11 | 关闭/退出 | hover 显示关闭按钮，彻底退出进程 | P0 |
| F12 | 单曲循环 | 循环按钮切换：开=播完从头重播，关=播完暂停；状态持久化 | P2 |

### 1.3 v1 明确不做（放到 v2+）
- 播放列表 / 多文件队列 / 上一首下一首
- 循环模式（列表循环；**单曲循环已支持**，见 F12）
- **专辑封面已支持**：Rust 命令抽取嵌入封面，无封面时回落占位图标
- 全局热键、系统托盘
- 歌词、可视化频谱
- macOS / Linux 支持

### 1.4 支持的音频格式
依赖 WebView2 (Chromium) 内置解码能力：**mp3、wav、ogg、m4a/aac、flac**。
拖入不支持的格式时：由 widget 自行判定并静默忽略（不提示），不改变当前播放状态。

### 1.5 交互边界与特殊情况
| 场景 | 期望行为 |
|------|----------|
| 一次拖入多个文件 | 仅取 `paths[0]`（第一个），忽略其余，不提示 |
| 拖入文件夹 / 不支持的格式 | widget 自行判定，静默忽略（不提示） |
| 拖入受支持扩展名但实际损坏/无法解码 | `<audio>` `error` 事件 → toast「无法播放该文件」，回到空闲态 |
| 播放中再拖入新文件 | 立即切换到新文件并自动播放（替换，不排队） |
| 同一文件重复拖入 | 重新从头播放 |
| 文件播放中被移动/删除 | `error` 事件 → toast「无法播放该文件」，回到空闲态 |
| 曲名过长 | 单行截断 + 省略号，hover 显示完整文件名（title/tooltip） |
| 时长未知（流式/异常） | 总时长显示 `0:00`，进度条不可拖 |

### 1.6 状态机
```
        ┌────────────┐  drop 受支持文件   ┌────────────┐
        │   idle     │ ─────────────────▶ │  playing   │
        │ (未播放)    │                    │  (播放中)   │
        └────────────┘                    └─────┬──────┘
          ▲       │                             │ 点击暂停
          │ error │ 点击暂停后播放结束            ▼
          │       └──────────────────────  ┌────────────┐
          └────────────────────────────── │  paused    │
                                          │  (已暂停)   │
                                          └────────────┘
```
- `idle`：未加载任何音频，曲名位显示「拖入音频以播放」。
- `playing` / `paused`：已加载音频，显示曲名、进度、时长。
- 播放自然结束（`ended`）→ 默认回到 `paused` 态并停在末尾；若开启单曲循环（F12）则从头重播，保持 `playing`。

## 2. 美术需求 (Art / Visual)

### 2.1 风格定义
- **无边框**：去除系统标题栏与边框，仅保留卡片本体。
- **现代化扁平**：纯色/微渐变背景，无拟物、无重阴影，圆角，细线条控件。
- ** draggable**：卡片主体区域可拖动移动窗口。

### 2.2 规格
| 项 | 值 |
|----|----|
| 尺寸 | 240 × 120 px（固定，DPI 缩放交由系统） |
| 圆角 | 12 px |
| 背景 | 深色扁平：`#1E1E24`（主）/ 可后续做浅色主题 |
| 强调色 | `#5B8DEF`（进度条、播放按钮高亮） |
| 文字 | 主 `#F2F2F5`，次 `#9A9AA5` |
| 字体 | 系统默认 sans（Segoe UI），曲名 13px / 时间 11px |
| 图标 | 线性图标（播放/暂停/喇叭/关闭），内联 SVG，不引图标库 |

### 2.3 布局（240 × 120）
```
┌────────────────────────────────────┐
│ ┌──────┐  曲名.mp3            ✕    │  ← 顶部留白区=拖拽区
│ │  ♪   │  ━━━━━━━○─────────        │  ← 进度条(可拖)
│ │      │  ▶   1:23 / 3:45   🔊┈○   │  ← 控制行
│ └──────┘                            │
└────────────────────────────────────┘
   64×64                                    边距 12px
```
- 左侧 64×64 封面占位（圆角 8，音符图标）。
- 右侧：曲名（单行截断）→ 进度条 → 控制行（播放/暂停、时间、音量）。
- 关闭按钮 `✕`：默认隐藏，鼠标 hover 卡片时淡入于右上角。
- **拖拽区**：卡片背景（非控件区）设 `data-tauri-drag-region` 以移动窗口。

### 2.4 状态与微交互
- **空闲（未播放）**：曲名位显示「拖入音频以播放」，进度条灰置。
- **拖拽悬停（文件在卡片上方）**：整卡高亮描边（强调色 1.5px）+ 背景微亮，提示「松开播放」。
- **播放中**：播放图标切为暂停；进度条按播放推进。
- **不支持格式**：卡片顶部滑入一条 toast，1.5s 后消失。
- 过渡动画统一 150ms ease，保持轻量。

## 3. 技术需求 (Technical)

### 3.1 窗口配置 (`tauri.conf.json`)
```jsonc
{
  "app": {
    "windows": [{
      "title": "desktop-card",
      "width": 240,
      "height": 120,
      "resizable": false,        // 固定大小
      "alwaysOnTop": true,        // 常驻最上层
      "decorations": false,       // 无边框
      "transparent": true,        // 背景透明以呈现圆角
      "skipTaskbar": false,
      "center": true              // 首次启动居中
    }]
  }
}
```

### 3.2 依赖（Rust / 前端）
| 依赖 | 用途 |
|------|------|
| `tauri-plugin-autostart` | 开机自启（注册表/启动项） |
| `tauri-plugin-store` | 持久化窗口位置 + 音量 + 自启开关 |
| `@tauri-apps/api` | `onDragDropEvent`、`convertFileSrc`、窗口 API |
| 前端 `<audio>` | 音频解码与播放（不引入 Rust 音频库） |

> **关键取舍**：v1 用 WebView 内置 `<audio>` 播放，而非 Rust rodio——零额外依赖、格式够用、进度/音量 API 现成。待需要全局热键/多设备输出时再评估 Rust 方案。

### 3.3 拖拽播放链路
1. 前端监听 Tauri `onDragDropEvent`（非纯 HTML5 drop，否则拿不到真实路径）。
2. `type: 'enter'/'over'` → 进入高亮态；`'cancel'` → 退出。
3. `type: 'drop'` → 取 `paths[0]`，交给当前 widget（`onDrop`），由 widget 自行判定。
4. `convertFileSrc(path)` → `asset://` URL（需在 capabilities 开启 `asset-protocol` 并配置可读路径范围）。
5. 设为 `<audio>.src` → `play()`。

### 3.4 位置记忆
- 监听窗口 `onMoved`，**防抖 300ms** 后写入 store `{ x, y }`。
- 启动时读取；有值则 `setPosition`，无值则 `center()`。
- 恢复到屏幕外（如曾接外接屏）时做边界保护，回落到居中。

### 3.5 开机自启
- `tauri-plugin-autostart` 的 `enable()/disable()`。
- 卡片上提供开关（右键菜单或设置入口，v1 可先用一个隐藏开关位），状态持久化。

### 3.6 无边框拖拽移动
- 卡片背景区加 `data-tauri-drag-region`。
- 交互控件（按钮、进度条、音量）默认不继承拖拽，确保点击/拖动不被吞。
- 注意与「拖文件到卡片」区分：文件拖拽由 drag-drop 事件处理，窗口移动由 drag-region 处理，二者不冲突。

### 3.7 风险与对策
| 风险 | 对策 |
|------|------|
| Windows 透明窗口阴影/点击穿透异常 | 早期先做最小透明窗口验证；必要时关闭系统阴影 |
| drag-region 与控件交互冲突 | 控件显式 `pointer-events` 与局部覆盖层验证 |
| asset-protocol 路径权限 | 在 capabilities 明确 scope；widget 内部对拖入路径做扩展名判定 |
| 多显示器位置失效 | 启动边界保护，越界则居中 |

### 3.8 持久化数据约定（store）
使用 `tauri-plugin-store`，单文件 `.json`。键名与默认值：

| key | 类型 | 默认 | 说明 |
|-----|------|------|------|
| `window.x` / `window.y` | number \| null | null | 窗口左上角坐标；null 表示首次启动用 `center()` |
| `volume.level` | number (0–1) | 0.8 | 上次音量 |
| `volume.muted` | boolean | false | 上次静音状态 |
| `player.lastFile` | string | "" | 上次播放的文件路径，重启恢复（加载不自动播放）；文件失效则清空 |
| `autostart.enabled` | boolean | false | 自启开关（与系统注册状态保持一致） |

- 写入时机：`window.*` 在 `onMoved` 防抖 300ms 后写；`volume.*` 在 change 后防抖 300ms 写；`autostart.*` 在开关切换时立即写。
- 读取时机：启动时一次性读取全部，缺键回落到默认值。

### 3.9 错误处理约定
- 前端 `try/catch` 包裹 `convertFileSrc` / `play()`，失败统一走 toast，不抛白屏。
- `<audio>` 监听 `error`、`stalled` 事件，映射为「无法播放该文件」。
- Rust 侧命令（自启 enable/disable）失败时返回 Err，前端 toast 提示并回滚开关 UI 状态。
- 所有 toast 复用同一组件，1.5s 自动消失，同时只显示一条（后到覆盖先到）。

### 3.10 目录结构（规划 / 已实施）
```
src/
  routes/+page.svelte        # 入口：模式分发（卡片 / ?mode=settings 设置窗口）
  lib/
    core/                    # 卡片平台层（与业务无关，所有 widget 共用）
      types.ts               # WidgetDefinition / WidgetStore / WidgetSetting 契约
      WidgetHost.svelte      # 外壳：窗口能力 + 拖拽分发 + 自启 + 位置记忆 + 托盘
      WidgetSearch.svelte    # Ctrl+F 搜索 widget（模糊匹配 + 键盘选择）
      SettingsPanel.svelte   # 平台设置表单：声明式渲染 widget 的设置项
      SettingsPage.svelte    # 设置窗口页（居中独立窗口，Esc 关闭）
      Card.svelte            # 卡片外壳 / 拖拽区 / 关闭按钮 / 拖入高亮
      window.ts              # 位置记忆、边界保护、防抖
      settings.ts            # 共享 store + 窗口位置 / 自启开关
    widgets/                 # 可插拔功能，每个是一个自包含 widget
      registry.svelte.ts     # widget 注册表 + 当前激活项 + Tab 循环切换
      audio-player/          # 例：音频播放器
        index.ts             # WidgetDefinition（拖拽判定 / 启动恢复 / 暴露组件）
        player.svelte.ts     # 播放状态机
        PlayerCard/Progress/Volume.svelte
      clock/                 # 第二个 widget：时钟/日期（默认）
        index.ts             # WidgetDefinition（不接收拖拽）
        ClockCard.svelte     # 时间日期显示
src-tauri/src/lib.rs          # 插件注册 + get_album_art
```

### 3.11 widget 机制（关键架构）
- **契约**：`WidgetDefinition` 包含 `id / name / keywords`（用于匹配）、`component`、
  `size`（声明窗口尺寸，切换时平台自动 resize）、`settings?: WidgetSetting[]`
  （声明式设置项）、`onSettingChange(key, value)`、`onDrop / dropHint`、
  `setup(store)`（启动恢复）。拖拽判定也在 widget 内：`onDrop(path)` 自行决定
  处理或静默忽略，平台只负责把路径交给当前 widget。
- **切换**：卡片聚焦时 Tab 在 widget 间循环；Ctrl+F 弹出搜索框，在
  name/id/keywords 上做子序列模糊匹配，方向键 + Enter 或点击选择切换。
- **设置**：设置窗口由平台统一提供（`SettingsPage` + `SettingsPanel`），
  widget 只声明可设置项。Ctrl+S 打开**居中独立窗口** `?mode=settings&widget=id`；
  改动经 `widget-setting-changed` 事件广播回卡片窗口（唯一写入者），卡片应用
  副作用（onSettingChange）并持久化到 store。
- **全局显隐**：Ctrl+Alt+Space 任意位置切换卡片显隐，显示时自动聚焦。
- **托盘**：卡片不占任务栏，✕ 收进托盘（音频不中断）；托盘左键显隐、
  右键菜单退出。开机自启在卡片右键切换。

## 4. 里程碑 (Milestones)

- **M1 窗口骨架**：无边框 + 透明 + 固定尺寸 + 最上层 + 可拖动 + 关闭按钮。验收：一张能拖动、置顶的深色圆角卡片。
- **M2 拖入即播**：drag-drop → `<audio>` 播放 + 曲名 + 播放/暂停 + 进度条(可拖)。验收：拖入 mp3 能播、能暂停、能跳进度。
- **M3 体验完善**：音量/静音 + 时长显示 + 不支持格式 toast + 拖拽悬停高亮。
- **M4 常驻能力**：位置记忆 + 开机自启开关。验收：移动后重启位置不变；重启电脑自动出现。
- **M5 收尾**：图标/打包名、边界保护、手测清单过一遍。
